## 🎨 The Square Image Solution

### The Problem
Gemini generates square images (1:1 ratio), but you need landscape backgrounds.

### The Solutions

#### ✅ Solution 1: Tiled Backgrounds (BEST!)
Use square images as seamless tiles that repeat.

**Perfect for**: Environment backgrounds  
**Difficulty**: Easy  
**Impact**: High

---

#### ✅ Solution 2: Layered Composition
Stack multiple square images (sky + mountains + foreground).

**Perfect for**: Depth and atmosphere  
**Difficulty**: Medium  
**Impact**: Very High

---

#### ✅ Solution 3: Center-Crop with Blur
Use square image in center, blur/fade edges.

**Perfect for**: Single focal point images  
**Difficulty**: Easy  
**Impact**: Medium

---

#### ✅ Solution 4: Portrait Panels
Use square images as-is for portraits and icons.

**Perfect for**: Heroes, monsters, items  
**Difficulty**: Very Easy  
**Impact**: High

## 🎨 Image Generation Tips

### For Best Results
1. **Always say "square composition"** or "centered"
2. **Use "dark fantasy style"** for consistency
3. **Specify colors** (e.g., "purple and black")
4. **Add "high detail"** for quality
5. **Say "no borders"** for seamless tiles

### If Image Isn't Perfect
- **Too bright?** → Add "dark moody lighting"
- **Wrong angle?** → Add "centered" or "top-down view"
- **Not detailed?** → Add "intricate details"
- **Wrong colors?** → Be more specific

### After Generating
1. Download as PNG
2. Rename with suggested filename
3. Save to correct folder:
   - `/assets/heroes/` - Hero portraits
   - `/assets/environments/` - Tiles and overlays
   - `/assets/monsters/` - Monster portraits
   - `/assets/icons/` - UI icons
