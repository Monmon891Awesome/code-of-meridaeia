## 💡 Tips for Best Results

### General Tips
1. **Generate multiple variations** - Pick the best one
2. **Be patient** - Sometimes takes 2-3 tries to get it right
3. **Save all versions** - You might want alternatives later
4. **Use consistent style** - "dark fantasy style" in every prompt

### If Image Isn't Perfect
- **Too bright?** Add "dark moody lighting" to prompt
- **Wrong composition?** Add "centered" or "square composition"
- **Not detailed enough?** Add "high detail" or "intricate details"
- **Wrong colors?** Be more specific: "deep purple, not light purple"

### After Generating
1. **Download as PNG** (best quality)
2. **Rename immediately** (use suggested filenames)
3. **Organize in folders**:
   - `/assets/heroes/` - Hero portraits
   - `/assets/environments/` - Tiles and overlays
   - `/assets/monsters/` - Monster portraits
   - `/assets/icons/` - UI icons
