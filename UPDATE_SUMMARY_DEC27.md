```

Level 41-50: 🏰 The Gates of Meridaeia (400-500 feet)
Level 50+:   ⚔️ Inside the Fortress (Boss Gauntlet)
```

### How It Works

- Each monster defeated = 10 feet deeper
- Background changes every 100 feet
- Lore snippets revealed randomly
- Depth meter shows progress
- Environment transitions with cinematic effects

## 📚 Collectible Relics System

### Four Types of Lore Items

1. **📜 Coding Cheat Sheets** (10% drop rate)
   - Quick reference PDFs
   - One-page visual guides
   - "10-year-old friendly" explanations
   - Topics: Streams, Pointers, TCP/IP, SQL, etc.

2. **📓 Programmer's Logs** (5% drop rate)
   - Story-driven wisdom from the Five Heroes
   - Programming lessons + Biblical principles
   - Example: "Memory leaks in code = unforgiveness in life"

3. **💎 Lost Treasure Files** (3% drop rate)
   - Actual code snippets with commentary
   - Programming lessons + life lessons
   - Example: Fibonacci + building on the past

4. **📚 Easy-to-Read PDFs** (Boss drops)
   - Comprehensive guides for beginners
   - Lots of pictures and analogies
   - Topics: "What is a Pointer?", "How the Internet Works"
